NASA MODIS Coastal Warming Anomaly Explorer

This interactive visualization explores coastal sea surface temperature patterns using NASA MODIS monthly imagery. The visualization summarizes each image into a regional warmth index, compares that value against the long-term average for the same month, and highlights warmer-than-normal periods over time.

How Unusual Are Ocean Temperatures Around the U.S.?

Hover or click a point to inspect that month on the map.

This visualization aims to compare sea temperature anomalies across different regions around the United States. Data on temperature anomalies are used to standardize data so that they are more comparable across different regions. A line graph was used in order to represent these temperature trends over time. We incorporated color into the line graph to visualize the temperature gradients derived from NASA satellite footage. We began with simple map images and created a simple line graph. We then transformed the line graph to incorporate colors from the NASA map images and to display per year based on the slider specifying year. We then scaled all the graphs to have the same y-axes to allow for more accurate comparison across regions.
